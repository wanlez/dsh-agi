# dsh-agi

[English](README.md)

DeepSeek Harness 的悬浮球智能体。跟它说话、把截图贴给它，让它操作你的桌面——然后让它记住你的流程到底怎么走，并且每执行一次就变得更靠谱一点。

本仓库 fork 自 [dsh-orb](https://github.com/mini-yifan/dsh-orb-cordis)（MIT，作者 mini-yifan），改名为 `dsh-agi` 并独立维护。

## 它凭什么不一样

| | |
|---|---|
| **说，不用敲** | 点一下头像开始听，说完再点一下结束。说「你好大肥鱼」唤醒并固定面板，说「退下吧」停止任务，说「大肥鱼」可在它干活时插话。唤醒词、语音识别、语音合成全部本地运行。 |
| **有人设，也有记性** | 角色卡决定每一轮由谁回答；配合经验库，同一个球在不同项目里可以像不同的专家。 |
| **经验是库，不是笔记** | 流程存成「节点库 + 各自独立的路径」。人写的文字是打底，AI 把真实执行学到的东西补在后面；人的截图始终是评判标准。 |
| **在输入框里就能维护** | 一句「帮我创建一个节点，内容是 xxx」就够了：七个经验库工具负责搜索、创建、检查、确认——而且确认是**代码强制**的，不只是提示词。 |
| **扛造的桌面操作** | 六套独立机制（见下）保证每次点击都真的落地、画面是新的、瞄的就是那个控件。 |
| **安全模式** | 你按下任何真实按键或移动鼠标，任务立刻停止；只有球自己注入的输入被忽略。停止不会结束对话。 |
| **自己的会话** | 球默认运行一个隔离的 `computer-use` 会话：它能操作桌面、使用经验库，主窗口同时保留自己的会话；也可在设置里切换为跟随主窗口最近活动过的会话。 |

## 经验库

Markdown 笔记会过期、会被跳过。`dsh-agi` 维护一个你真能长期用的库，而且设计上让「AI 自己的经验」能持续改进它，又不会覆盖你的内容。

### 节点：一步一个包

- **标题 + 人写的说明**——操作者自己的话，是 AI 每次最先读的打底。
- **AI 补充（`ai_notes`）**——只由 AI 在真实执行之后写入：坑、更准的提示、下次该盯什么。**人写的文字永远不会被改写。**
- **带来源的截图**——人的截图是**核心评判标准**，AI 截图的身份是「执行指导」；两者都存在同一个节点包里，标注 `human` / `ai`。
- **就地查看/编辑**——编辑器里人写区块和 AI 区块分开展示，你随时能看到它学到了什么，同时保留自己措辞的权威。

### 路径：看得懂的节点图

- 一条路径拥有**节点实例与边的有向图**，不是一条平铺的列表。两条箭头汇进一个节点就是汇合，两条箭头出去就是分支。
- 同一个节点可以出现多次。**重复不等于成环**：会不会绕圈取决于边，每次插入都会在实例图上做真正的环检测（Kahn 算法）。
- 画布画成圆圈加箭头，每个位置带一个显示编号（1..N）。编号每次渲染重算：同一个节点的两个实例也分得清，编号不会跳号或留空。
- 插入对话框给三个来源：本路径内已有位置、搜索结果、收藏节点。选中已有位置＝**只加一条连到那个位置的边**，不会重复加节点；选库里的节点＝新建一个位置并连线，节点本身不会被复制。
- 节点和路径都能复制（`_复制版_<时间戳>` 命名），也能导出到空文件夹（JSON + 截图 + manifest）再原样导入；id 冲突时自动换新 id，不会覆盖已有内容。
- 改一个节点，会同时改善**所有**引用它的路径——一处修好，处处生效。

### 执行之前先检查

路径支持随时检查和保存时检查：

- 引用的节点是否都还在、没被软删除；
- 每条边是否都指向本路径里的节点；
- 图是否**无环**——用真正的环检测，而不是「这个节点重复了没有」；
- 记录的起点/终点是否属于这条路径；
- 必填字段（标题、说明、截图说明）是否为空。

检查只读数据、不碰桌面。有问题的路径不可能悄悄走到真实机器上。

### 输入框驱动 + 双重约束

输入框可以通过七个工具直接维护经验库：

| 工具 | 作用 |
|---|---|
| `knowledge_graph_search` | 创建前先找已有节点/路径，候选原样交给操作者决定复用还是新建。 |
| `knowledge_graph_get_node` | 读节点，含 AI 补充、以及每张截图是人的还是 AI 的。 |
| `knowledge_graph_create_node` | 建节点；同名时**拒绝**，除非操作者明确说要新建；支持把同一条消息里附带的截图一起存进去。 |
| `knowledge_graph_create_path` | **只有在明确确认之后**才保存路径：`steps` 实例列表 + 可选 `edges`（`[from, to]` 实例下标对，缺省是一条直线）；同一节点可在不同位置重复，只有边真的绕回来才算环，成环和缺失节点会被拒绝，保存后自动检查。 |
| `knowledge_graph_check_path` | 跑静态检查，逐条报告问题。 |
| `knowledge_graph_update_node` | 修人写的标题/说明——措辞仍归操作者。 |
| `knowledge_graph_learn_node` | 真实执行后**只**更新 AI 部分：`ai_notes`（限 600 字、最多 3 条要点）和 AI 截图；没有新东西就跳过。 |

安全顺序被实现了两遍：代码拒绝未确认的写入，提示词则规定流程——先搜索、逐节点和操作者确认、最后检查并报告。创建路径时还会先明确提醒「路径创建较复杂，请务必打开经验库核对每个细节」，让操作者始终在环里，而不是被惊喜。

## 扛造的桌面操作

桌面自动化总在无聊的地方失败：弹窗占着窗口时点下去、截图还是改动前的帧、窗口移动或副屏 DPI 不同导致坐标偏了。Windows 层借鉴了 [Windows-MCP](https://github.com/CursorTouch/Windows-MCP) 的六个工程思路，把每种失败变成模型看得见的信号：

| 失败 | `dsh-agi` 的做法 |
|---|---|
| **点进被阻塞的窗口** | **动作回执**。点击前原生层会报告「前台被禁用且存在子对话框」，调用返回结构化的弹窗警告和真实选项（`press-esc` / `focus-modal` / `ask-user`），而不是盲目点下去。 |
| **「这一下到底有没有生效？」** | **动作后校验**。动作之后重新采样同一目标，记录四件事：焦点是否保持、前台是否稳定、目标是否变为禁用、窗口是否移动到足以让坐标失效。 |
| **画面是旧的** | **帧新鲜度 + 兜底截图**。每次截图前跑 `DwmFlush`，保证拿到的是合成后的帧；BitBlt 失败或全黑时切到 `PrintWindow(PW_RENDERFULLCONTENT)`；兜底帧再退化也会返回原始位图加追踪信息，不会抛异常把截图弄丢。 |
| **看着对准了、其实没中** | **悬停探测**。预览阶段把指针移上去前后各截同一小块，报告控件是否真的响应——带容差的像素差分，抗锯齿和亚像素抖动骗不了它。 |
| **屏幕/DPI 不对** | **显示器清单**。按 per-monitor-v2 DPI 感知枚举每块屏的物理和逻辑矩形；一次换算完成「归一化坐标 → 窗口矩形 → 所在屏 → 物理像素」，并把清单写进观察信封。 |
| **「读不到」被当成「没有」** | **三态观察 + 文本卫生**。每个字段都是 `provided` / `empty` / `unsampled`（权限、超时、不支持），读失败绝不会伪装成空界面；所有给模型的文本都会清洗：私用区移除、零宽字符剔除、孤立代理修复、换行转义、截断显式标注。 |

观察光晕（AI 接管时画的边框）通过 `WDA_EXCLUDEFROMCAPTURE` 从所有截图里排除，永远不会污染模型看到的画面。

## 版本记录

每个版本单独一节，最新的在最上面，方便直接对比「上一版到这一版改了什么」。

### 0.7.0

网页层、经验库和桌面通道不再是三件互不相干的事：一条能力阶梯决定每一步走哪个通道，网页通道开始用代码跑整条流程，而不是让模型盯着页面猜。

**网页控制（默认关闭，20 个工具）**
- 设置 → 悬浮球 → 网页控制。开关关闭时工具立刻从模型侧消失，重新打开立即注册，无需重启。
- 读结构、按名字操作：`web_find` 统一规范化名字（全半角、大小写、空白），只有唯一命中才动作；`web_click` / `web_type` / `web_select` / `web_hover` / `web_upload` 接收的是名字而不是坐标，同名命中两个就拒绝执行而不是猜。
- 内网后台需要的覆盖：所有 iframe（含跨域）、递归 open shadowRoot、弹窗自动跟随、标签页列出与切换（`web_pages` / `web_switch`）、虚拟列表滚轮滚动（`web_scroll`）、不弹系统框的上传、浏览器崩溃后自愈一次。
- 校验是通道的一部分：`web_wait` 等 URL 片段、页面文字或选择器，`web_text` 读页面真实文字，所以不存在"点完就当成功"。
- 流程执行器，回路里没有模型：`web_flow_save` 保存流程（`click` / `type` / `select` / `hover` / `press` / `wait` / `open` / `back` / `upload` / `scroll`），`web_run_flow` 逐步执行——唯一命中、`expect` 校验、失败即停——默认 `dryRun`，先让操作者看到会点哪个控件。已保存的流程重跑，模型调用为 0。
- 三种浏览器来源，选什么就是什么：内置 Chromium 启动 Chromium，系统 Chrome 启动 Chrome，连接模式只连 CDP 端口。选中的模式缺前置条件时，面板直接提示，网页步骤自动改用键鼠，而不是把任务判失败。
- 接管当前 Chrome（操作者授权）：插件可以请 Chrome 关闭、用操作者自己的配置带本地回环调试口重启并连上，登录态和扩展原样回来，因为不复制、不移动任何东西；关不掉的窗口只报告，绝不强杀。
- 远程桌面、虚拟机和远控软件只是提示，永远不是停用理由：浏览器永远跑在本机，通道照常工作，只有页面真的读不到时才落回键鼠。

**能用嘴改的经验库**
- `knowledge_graph_list` / `get_path` / `update_path` / `delete` / `relations` / `link` 补齐工具面：列出有什么、读整条流程、原地改名或重排、查某个节点被哪些路径用到，以及给出本地深链（`http://127.0.0.1:<端口>/#/node|path/<id>`），点开就定位到那一条。
- 删除有护栏：仍被路径引用的节点拒绝删除并列出路径；删路径不连带删节点。
- 修掉一处静默丢数据：`updatePath` 只推进了索引，从没写 `paths/<id>.json`，改名和重排看着成功、重新加载就没了。新增回归测试，用新服务重新读盘验证。
- 只读 UIA 辅助：`uia_snapshot` 列出前台窗口的控件名、类型、矩形和窗口内中心点，指针工具可直接用。它不调用控件、不读写值；树太薄（Qt、Flutter、旧 Win32）会明确报不可用。

**一套策略，而不是三套**
- 能力阶梯只放在预设里（`cordis.patch.yml`）：API/命令行 → 文件与进程 → 网页 → 启动应用 → UIA 定位 → 截图与输入。每轮注入不再重复一条相互冲突的"默认键鼠"。
- 全新安装和升级后的球会话默认隔离，会话属于它自己；只有设置里做出的选择才会被记住。

## 安装

**推荐：设置 → 插件**，在那里安装 `dsh-agi`。插件管理器会同时写依赖和 `dsh.profile.bundles`，装完重启即可。

命令行安装（两步，缺一不可）：

```powershell
& "<DSH 安装目录>\resources\runtime\cli\bin\dsh.cmd" plugin --profile desktop add dsh-agi@0.6.19
```

`dsh plugin` 只是把参数转发给 pnpm，**不会**把插件写进 `dsh.profile.bundles`，所以还要跑一次包里的启用脚本：

```powershell
& "$env:USERPROFILE\.dsh\profiles\desktop\node_modules\dsh-agi\install.cmd"
```

它会写好 loader 条目、检查原生模块，然后提示重启。之后完全退出并重新打开 DeepSeek Harness。

npm 不可达时，从 [Releases](https://github.com/wanlez/dsh-agi/releases) 下载最新 `.tgz`，用 `dsh plugin add "<tgz 的绝对路径>"` 安装，再跑同一条 `install.cmd`。

安装包自带代码与运行时依赖（语音、原生模块），安装过程不会访问其他 registry；Electron 运行时与语音模型仍在首次使用时下载。

### 旧版本的安装报错（0.6.18 及以前）

老包把 `koffi` 当运行时依赖，而它的二进制要靠 `install` 脚本现编，pnpm 的构建脚本策略会拦下它（`ERR_PNPM_IGNORED_BUILDS`，退出码 1）——包其实装好了，但命令报失败。0.6.19 起改为依赖预编译平台包（`@koromix/koffi-win32-x64`），不再有构建脚本，退出码就是 0，也**不需要**任何 `allowBuilds` 配置。

### 卸载

插件目录里还有 `uninstall.cmd`：删除插件包与加载条目、语音模型与运行时缓存，保留经验库、球工作区与会话留档。

## 怎么用

- **语音**：点球上的头像开始听，说话，再点一下结束；停顿一秒也会自动结束。语音和打字走同一条路径。
- **图片**：在面板输入框里按 Ctrl+V 贴截图（每条消息最多九张），和文字一起发送。
- **角色卡**：设置 → 悬浮球 → 角色卡。新建或选一张卡，之后每轮都由这个角色回答。
- **经验库**：设置 → 悬浮球 → 经验库，或悬浮球右键 →「进入经验库」。搜节点查看/编辑，搜路径看整条流程；在路径视图里插入、重排、检查步骤。也可以直接在输入框说「创建节点：xxx」「创建路径 A→B→C」，然后确认它列回来的步骤。
- **唤醒词**：球收起时说「你好大肥鱼」（或你配置的短语），面板会打开并固定，球本地回答「我在呢」。唤醒短语、回应、阈值、判定粒度和 1.5 秒冷却都可改。9MB 唤醒模型首次使用从本仓库下载。干活时说「大肥鱼」可以插话，说「退下吧」停止并取消固定。

## 安全模式与状态药丸

- **三色状态**：球面板里的药丸显示它在干什么。蓝点=思考中，绿点=操作中（点击或按键落地前约 0.35 秒变绿，留出反应时间），任务结束或停止后红点=未工作五秒。没有任务时隐藏。
- **安全模式**：设置 → 悬浮球 → 安全模式。开启后，你按任何键、移动鼠标或点击都会立刻停止当前任务，效果等同停止按钮。球自己注入的输入带 Windows 注入标记，不会触发它。
- **停止不等于结束对话**：会话和上下文都保留，继续打字或说话，它会接着干。

## 更新

设置 → 悬浮球 → 检查更新。检查优先 npm（npmmirror，再 npmjs），GitHub Releases 兜底；升级优先用 npm 上的 `dsh-agi@version`，npm 不可达时用 release tarball。默认每天自动检查一次。
